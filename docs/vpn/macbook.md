## MacBook WireGuard Config

Install WireGuard from the Mac App Store. Add Empty Tunnel and paste:

```ini
[Interface]
PrivateKey = <generated by WireGuard app — do not replace>
Address = 10.0.0.3/32
DNS = 192.168.1.1
MTU = 1420

[Peer]
PublicKey = izx9UGkIj2dslFOgakjXY7cg96rMhpcZkV6AKy78/ys=
AllowedIPs = 192.168.1.0/24, 192.168.10.0/24, 192.168.20.0/24, 10.0.0.0/24
Endpoint = vpn.mystikal.dev:51820
PersistentKeepalive = 25
```

!!! note
    The `[Peer] PublicKey` is OPNsense's wg0 public key — not the Mac's key. The Mac's public key goes into OPNsense as the peer's public key.

## Split Tunnel

| Traffic | Route |
|---|---|
| 192.168.1.0/24 (Management) | Through VPN |
| 192.168.10.0/24 (Servers) | Through VPN |
| 192.168.20.0/24 (Trusted) | Through VPN |
| 10.0.0.0/24 (WireGuard) | Through VPN |
| All other traffic | Direct internet |
